## 📊 Project Overview
This repository contains an enterprise-grade **Power BI Dashboard** engineered for **Shield Insurance**. The project integrates complex insurance datasets to provide actionable insights into customer acquisition, policy distribution, revenue streams, and demographic shifts. It serves as a centralized decision-making tool for executives to monitor operational health and optimize marketing spend.

---

## 🎯 Purpose of the Project
The primary objective of this project was to dissolve data silos within Shield Insurance and provide a unified tracking system for management. Historically, sales channels and demographic data were monitored independently, masking critical trends. This dashboard unifies these elements, allowing stakeholders to track revenue health, isolate underperforming sales channels, and design tailored insurance products for targeted age cohorts.

---

## 🔑 Key Features & Dashboards
The _[Power BI report](https://github.com/Nidhi-DA/Insurance-Dashboard/blob/main/Shield_Insurance_project%20-2.pdf)_  consists of three core analytical environments:
1. [Home](https://github.com/Nidhi-DA/Insurance-Dashboard/blob/main/Home.png) : Navigation hub providing clean links to all report pages.
2. [Overview Dashboard](https://github.com/Nidhi-DA/Insurance-Dashboard/blob/main/Overview.png) : A high-level executive summary tracking total revenue, active customers, key performance indicators (KPIs), and historical trend timelines.
3. [Sales Mode Analysis](https://github.com/Nidhi-DA/Insurance-Dashboard/blob/main/Sales%20Mode%20Analysis.png) : A deep-dive environment focusing on distribution efficiency across various channels (e.g., Digital, In-Person Agents, Third-Party Brokers) to pinpoint customer acquisition costs and margin strengths.
4. [Age Group Analysis](https://github.com/Nidhi-DA/Insurance-Dashboard/blob/main/Age%20Group%20Analysis.png) : A demographic split view segmenting performance by customer age brackets, highlighting premium preferences, policy alignment, and growth opportunities.

## 🛠️ Technologies & Skills Used
* **Power BI Desktop & Service**: Data modeling, cloud publishing, and dashboard administration.
* **Advanced DAX**: Engineered complex calculated measures for dynamic aggregations and KPI tracking.
* **Power Query & M Code**: Executed data profiling, cleaning, structural transformation, and schema validation.
* **Data Modeling**: Structured an optimized Star Schema with distinct Fact and Dimension tables for fast filtering.
